## Predeclared admission rules

Every frozen case must reach its selected-audio end with valid output for candidate admission. Missing, cancelled, incomplete, malformed, or technically failed cases fail the gate. A known speech-over-background-music foreground false positive disqualifies foreground admission. Unsupported specific genres on known vocal controls and an unreviewed native-to-IAB mapping disqualify specific-genre admission. Suitable rights and a reproducible MLX-only runtime are also required. Unknown or provisional routing labels cannot establish calibrated foreground performance.

YAMNet's N-by-521 frame score matrices are diagnostic observations. No reviewed foreground rule or native-to-IAB mapping is frozen, so high music scores do not establish foreground music, genre, or admission. MOSS uses its unchanged fixed prompt, greedy temperature 0, and maximum 2,048 generated tokens. Reaching that cap is an incomplete technical result even if the returned text resembles JSON. Strict native observations are preserved; malformed output is never repaired or coerced. Instrumental, non-English, and environmental/silence controls retain their original out-of-scope routing regardless of acoustic genre output.

There is a frozen prompt/parser asymmetry: the prompt explicitly requires genre null for `uncertain`, while the parser additionally forbids a genre when foreground is `no`. This can cause a returned observation to fail the experimental contract without proving that the model cannot describe the audio. The current run preserves both the prompt and the stricter parser; it does not repair outputs or revise the contract after seeing results.

This plan has no reviewed native-label to descendant-of-`338` IAB mapping. No mapping is proposed or admitted by this note. A later mapping proposal requires separate label-by-label review.

## Measured outcome

All 170 YAMNet inputs completed their full selected PCM extent. Each unit retains every frame's 521 raw scores; no score-to-genre interpretation is made.

Corrected MOSS case 001 (TV `-01--.mp4`, source 60–180 seconds) returned foreground `yes` and native genre `movie` in local 0–30 seconds, then foreground `yes`/genre null in local 30–60 seconds. Local 60–90 seconds failed strict parsing because nonforeground output also named a genre. The case stopped at that technical failure with only two of four windows accepted; the last window was not inferred. It is not a successful full-clip result. Elapsed time was 56.42 seconds, process peak RSS 10,545,528,832 bytes, and MLX peak memory 10,945,502,640 bytes. Native `movie` is not an admitted IAB genre and the provisional TV routing does not constitute reviewed foreground gold.

The corrected MOSS failures are exactly 46 `InvalidMossOutput: nonforeground audio cannot name a genre` and 21 `IncompleteGeneration: INCOMPLETE_GENERATION: token cap reached`. Of the 46 contract errors, 41 returned foreground `no` with a non-null string (including 13 literal `"null"` strings); five returned `uncertain` with the literal string `"null"`. The former group must be read alongside the frozen prompt/parser asymmetry, while the latter directly conflicts with the prompt's explicit uncertain/null instruction. The 21 capped generations were not assumed complete. These are measured failures of this experimental output contract, not proof that all 67 clips were acoustically misunderstood. No corrected terminal attempt was retried. The eleven older preflight failures and interrupted YAMNet artifact remain separate historical attempts and are not counted as extra distinct corpus cases.

MOSS scheduled 327 windows across the 170 cases. It returned 279 windows spanning 6,670 seconds and strictly accepted 212 windows spanning 5,515 seconds; remaining windows were not run after the first technical failure in their case. This falls short of the frozen 8,058.0838425-second corpus and fails the complete-case gate. There are zero missing predeclared model/case results; incomplete window coverage is retained explicitly, not called complete or silently omitted.

Across the 103 complete MOSS cases, 41 contain more than one non-null native label across windows. Labels include music descriptions such as `pop/rock ballad`, but also `speech`, `tutorial`, `voiceover`, `movie`, and the literal string `null` (distinct from JSON null). No normalization, merging of case variants, or conversion to IAB IDs occurred. This is descriptive variation, not an independently labeled genre-consistency accuracy score. The per-window observations below expose the variation directly.

The frozen corpus has no routing role exactly equal to reviewed `speech_with_background_music`; its speech cases retain background-unknown or provisional provenance. Therefore the comparison's zero formal foreground-false-positive flags is **not** evidence of zero mistakes. Foreground `yes` with speech-like native labels is a concrete concern visible in the table, but foreground/background error rates cannot be established from the available reviewed gold. No new gold was inferred from these outputs. All instrumental, non-English, and environmental/silence cases retain the frozen routing roles in the machine comparison even when a native label was produced.

A frozen-inventory defect is present in SAM B (case 168): its executable routing role is `vocal_music_language_provisional`, contradicting the retained prior listening-confirmed `item-moving sounds only` label, `vocal_presence: absent`, and warning that the singing filename is misleading. The earlier version of this note incorrectly called the role `unknown_provisional`; this paragraph corrects that factual error. The saved comparison retains the contradictory vocal-music role and MOSS foreground `yes` / native `video game` for five seconds. The manifest, raw reports, and saved comparisons have not been relabelled or rerun. This defect fails preservation of the known negative-control routing, so these results cannot certify correct negative-control routing. `no_acoustic_candidate` remains supported; any future corrected protocol requires separate provenance and review. Table references to unknown original extent concern source lineage; SAM's earlier documentation records 60–65-second excerpts without establishing the source-stream identity.

YAMNet remains ineligible for foreground or specific-genre admission because its raw scores have no reviewed foreground calibration or IAB mapping in this protocol. MOSS additionally fails on 67 technically incomplete cases. Unreviewed routing gold and mapping are distinct reasons from measured technical failures; `no_acoustic_candidate` is not presented as a blanket judgment of model quality.
